Rol del servicio:
Principalmente se utiliza para aislar la lógica de negocio del carrito como lo es el agregar, actualizar
cantidad y eliminar.

Observables:
Sirve para mantener el ultimo estado del carrito y mandar cualquier nueva información que ingrese, Ademas
de que se actualiza sin necesidad de recargar toda la pagina.

Pipes:
Sirve para tomar el precio unitario del producto y su cantidad para así poder realizar el subtotal y total.
Contribuyendo en no tener que ponerlo en lo que es la plantilla del HTML y así dejándolo mas limpio.
